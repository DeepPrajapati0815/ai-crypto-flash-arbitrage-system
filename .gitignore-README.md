## `.gitignore` Coverage

### Rust/Cargo
- `target/` - Build artifacts
- `*.rlib`, `*.rmeta` - Compiled libraries
- Incremental compilation cache

### Python/ML
- `venv/`, `env/` - Virtual environments
- `__pycache__/`, `*.pyc` - Python cache
- `ml_training/models/*.onnx` - Trained models (large binaries)
- `ml_training/data/*.csv` - Training data

### Secrets & Config
- `.env`, `.env.*` - Environment variables
- `*.key`, `*.pem` - Private keys
- API credentials

### IDE & Editors
- `.vscode/`, `.cursor/`, `.idea/` - IDE configs
- `*.swp` - Vim swap files

### Database
- `postgres_data/`, `redis_data/` - Database volumes
- `*.db`, `*.sqlite` - Local databases

### Logs & Temp
- `*.log` - Log files
- `*.tmp`, `*.temp` - Temporary files

### OS-Specific
- `.DS_Store` - macOS
- `Thumbs.db` - Windows
- `*~` - Linux backups

## `.dockerignore` Coverage

### Excluded from Docker Build Context:

**Documentation** (not needed in container)
- `*.md` files (except README.md)
- `docs/` directory
- Implementation guides

**Development Files**
- `.git/` - Git history
- `.vscode/`, `.idea/` - IDE configs
- `tests/` - Test files

**Build Artifacts** (rebuild in container)
- `target/` - Rust build artifacts
- `venv/` - Python virtual env

**Large Files** (mount as volumes)
- `ml_training/data/` - Training data
- `ml_training/models/` - Trained models
- Database files

**Scripts** (development only)
- `setup_env.ps1`
- Test and deployment scripts

## Important Notes

### Models & Data
Large binary files (`.onnx`, `.pkl`, `.csv`) are **ignored by git** but should be:
- Stored in cloud storage (S3, GCS)
- Mounted as Docker volumes
- Downloaded during deployment

### Environment Files
- `.env.example` is **tracked** (template)
- `.env` and `.env.*` are **ignored** (contain secrets)
- Always use environment variables for secrets

### Database Migrations
- `migrations/*.sql` are **tracked** (version controlled)
- Database data directories are **ignored**

## Best Practices

### Before Committing

```powershell
# Check what will be committed
git status

# Verify sensitive files are ignored
git status --ignored

# Check for accidentally tracked secrets
git secrets --scan
```

### Model Management

```powershell
# Store models in cloud
aws s3 cp models/trading_model.onnx s3://your-bucket/models/

# Download in production
aws s3 cp s3://your-bucket/models/trading_model.onnx models/
```

### Docker Build Optimization

```powershell
# Check Docker context size (should be small)
docker build --no-cache --progress=plain -t test .

# Verify ignored files aren't in context
docker build --no-cache -t test . 2>&1 | grep "Sending build context"
```

## Sensitive Files Checklist

Ensure these are **never** committed:

- [ ] `.env` files with API keys
- [ ] Private keys (`.key`, `.pem`)
- [ ] Database credentials
- [ ] Wallet private keys
- [ ] Training data with PII
- [ ] Large model files (use Git LFS or cloud storage)

## Troubleshooting

### "File still tracked after adding to .gitignore"

```powershell
# Remove from git cache
git rm -r --cached target/
git commit -m "Remove ignored files"
```

### "Docker build too slow / context too large"

```powershell
# Check context size
docker build --no-cache . 2>&1 | Select-String "Sending build context"

# Verify .dockerignore
docker build --no-cache --progress=plain . 2>&1 | Select-String "COPY"
```

### "Accidentally committed secrets"

```powershell
# Remove from history (use with caution)
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch .env" \
  --prune-empty --tag-name-filter cat -- --all

# Or use BFG Repo-Cleaner
bfg --delete-files .env
```
